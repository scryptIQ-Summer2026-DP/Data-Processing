Data Processing 3 - Glossary

Glossary DP3
Pixel: The smallest individual unit of a digital image. In a raster image, each pixel stores a numerical value that represents brightness in a greyscale image, or colour information in a colour image.
Brightness: The overall lightness or darkness of an image, which in Python image handling can be adjusted by increasing or decreasing the numerical intensity values of the pixels.
Contrast: The difference in intensity between darker and brighter regions of an image. Increasing contrast stretches the differences between darker and brighter pixels, making features stand out more clearly.
Exposure: A description of how much light is captured when an image is made. Underexposure makes an image too dark (crushing details to black), while overexposure makes it too bright (blowing out details to white).
False Colouring: The deliberate reassignment or transformation of an image's colour channels so that structures are displayed in colours different from those in the original image.
Colour Space: A system for representing colours numerically, by describing each pixel using a defined set of components (such as RGB or HSV).
HSV (Hue, Saturation, Value): A colour space that represents each pixel using hue, saturation, and value, rather than red, green, and blue intensities.
Hue: The component of the HSV colour space describing the dominant perceived colour of a pixel (such as red, green, blue, or yellow).
Saturation: The component of the HSV colour space describing how pure or intense a colour is, ranging from grey and washed-out to vivid and fully coloured.
Value: The component of the HSV colour space describing the overall brightness of a pixel, ranging from dark to bright.
Segmentation: The process of partitioning an image into distinct, meaningful regions, such as dividing an image into signal and background.
